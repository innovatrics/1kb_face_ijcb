# Exact package versions of the environment that produced the paper results
# (Python 3.11.11, Linux x86_64, CUDA 12.8 wheels, NVIDIA driver with CUDA >= 12.8).
#
# This is the complete dependency closure of the packages the code imports, so it
# is meant to be installed WITHOUT dependency resolution:
#
#     python3.11 -m venv .venv && . .venv/bin/activate
#     pip install --no-deps -r requirements/paper.txt
#     pip install --no-deps -e .
#
# (scripts/setup_env.sh --paper does exactly this, after checking for Python 3.11.)
# The environment is not reachable by dependency resolution: compressai 1.2.8
# declares numpy<2, while the paper environment ran numpy 2.4.6 (and
# opencv-python-headless 4.13, which needs numpy>=2), so `pip check` reports that
# conflict here. Installing without --no-deps would also pull the CPU-only
# `onnxruntime` (an insightface requirement, which shadows onnxruntime-gpu) and
# `opencv-contrib-python` (a mediapipe requirement), neither of which was present in
# the paper environment. A resolved install (`pip install -e ".[...]"`) gets numpy
# 1.26 and opencv-python-headless 4.11 instead.
#
# Several pins (numpy 2.4.6, scipy 1.17.0, pandas 3.0.0, matplotlib 3.11.0,
# scikit-image 0.26.0, contourpy 1.3.3) need Python >= 3.11; use Python 3.11.
#
# Notes
# * torch==2.10.0 from PyPI is the CUDA 12.8 build; the nvidia-* wheels below are its
#   CUDA runtime.
# * openai-clip==1.0.1 is the PyPI distribution of OpenAI CLIP that pyiqa requires and
#   that the adversarial study used. It packages an older revision of
#   github.com/openai/CLIP whose ViT code path (ViT-B/32, the only CLIP model used)
#   is identical to github.com/openai/CLIP at commit ded190a0; it imports
#   pkg_resources, which setuptools 82 removed (setuptools is pinned below).
# * mediapipe is installed without its dependencies on purpose (see above).
